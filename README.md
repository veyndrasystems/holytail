# Holytail operator package

This personal dotagents source contains the portable `holytail` meaning gate,
the bounded `holytail` implementation agent, the optional independent
`semanticreviewer`, and one global routing fragment.

The default path is lightweight and inline: preserve the meaning already clear
from the user's request and accepted project instructions, leave the remaining
mechanism open to experimentation, and only then apply Ponytail-style economy.
The formal contract, separate worker, and independent reviewer are escalation
tools for meaning-rich or high-risk work, not mandatory ceremony for every
coding task.

`agents.toml` is the distribution source of truth. Generated Codex and Claude
profiles must not be edited directly. Apply `fragments/global-routing.md` to a
host's global instruction file when migrating this package to another server.

Soulmate remains the project-specific authority and evidence layer. This
package adds no Soulmate persisted format and does not initialize projects.
